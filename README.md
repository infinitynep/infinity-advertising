# Infinity Advertising Pvt. Ltd. — Official Corporate Website

> **An Odyssey of Creativity...**

Official corporate web application for **Infinity Advertising Pvt. Ltd.**, a premier full-service creative advertising agency based in Tripureshwor, Kathmandu, Nepal.

---

## 🎨 Overview & Brand Direction

Inspired by international creative studios and advertising agencies, this website features:
- **Visual Style**: Modern, minimal, spacious editorial hierarchy, bold typography in Manrope & Inter.
- **Brand Colors**:
  - Primary Blue: `#0877B9`
  - Cyan Accent: `#08A9E0`
  - Dark Charcoal: `#29292D`
  - White & Light Grey: `#FFFFFF` / `#F2F4F6`
- **Dynamic Elements**: Smooth scrolling, flowing infinity line motifs, reactive cards, and interactive modal dialogs.

---

## 🚀 Key Features & Website Sections

1. **Header & Navigation**: Sticky header with official logo, smooth scrollspy links, mobile drawer, and "Let's Talk" CTA.
2. **Hero Section**: Large editorial headline *"Creativity That Moves Brands Forward."*, supporting copy, and animated infinity emblem.
3. **About Infinity ("Who We Are")**: 6 agency pillars and an interactive expandable drawer for sister production facilities (*Dream Vision Studio*, *National Offset*, and *Maya Screen Print*).
4. **Our Services**: 3 comprehensive pillars (*Brand Development*, *Advertising Solutions*, and *Event Management*) with deep-dive detail modals.
5. **Portfolio / Our Work**: International agency-style gallery with category filter tabs (*Branding*, *Advertising Campaigns*, *Digital Campaigns*, *Event Management*, *Photography*, *Videography*) and interactive case study modals.
6. **Our Philosophy**: *"Creative Thinking. Meaningful Results."* detailing measurable ROI, sustainable growth, and sales-driven execution.
7. **Our Process**: 5-step visual roadmap: `LISTEN` → `THINK` → `SOLVE` → `EXECUTE` → `LAUNCH`.
8. **Our People**: Collaborative culture principles (*Creative Minds. Collaborative Spirit.*).
9. **Our Valuable Clients**: 24 verified corporate & institutional partners with live text search and industry filtering.
10. **Testimonials**: Interactive carousel with pagination indicators and quote transitions.
11. **Blog & Insights**: Starter thought leadership articles with reading modal and social share tools.
12. **Contact Section**: Address (*Blue Star Complex, 6th Floor (609), Tripureshwor, Kathmandu*), clickable phone (`+977-1-5347277`), official email (`infinity.nep@gmail.com`), validated inquiry form, direct email mailto trigger, and Google Map.
13. **Footer**: Official branding, quick links, headquarters details, and back-to-top button.
14. **SEO & Accessibility**: LocalBusiness JSON-LD schema, canonical URLs, semantic tags, Open Graph, Twitter cards, XML sitemap, and robots.txt.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS 3.4
- **Icons**: Lucide React

---

## 💻 Development & Build

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
